# FindIt Development Rules

This is a Laravel 13 + Livewire 4 application.

## Rules

- Inspect the code before making changes.

- Follow Laravel conventions.

- Prefer Livewire over JavaScript when practical.

- Never modify .env.

- Never change database credentials.

- Never run migrate:fresh.

- Never delete migrations.

- Never remove authentication.

- Never commit automatically.

- Never push automatically.

- Explain architectural changes before implementing them.

## Goal

Build a detective game engine capable of supporting many investigations.
